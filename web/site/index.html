Accurate at every step

Your event data stays in a database only you control. Here’s how we keep every record correct.

  • Confirmed by youEvery registration is confirmed by an organizer, or by a rule you set. Events can never raise their own capacity.
  • Your records stay yoursEventra keeps everything in your own MySQL database, so nothing leaves without you.
  • Checked registrationsEvery registration is checked for duplicates and seat limits before it is saved, and every check-in is logged.

Frequently asked questions

Anything else? Open an issue on GitHub.

  • What is Eventra?

    Eventra is an Event Registration Management System. It manages event details, participant registration, event schedules and participant records from one dashboard.

  • Do participants need an account?

    No. Participants register through a link or at the desk. Organizers sign in to the dashboard to manage events and records.

  • Can an event go over capacity?

    No. Every event has a seat limit. Once it is full, new registrations go to the waitlist, and only an organizer can raise the limit.

  • Can I register someone who isn’t on Eventra?

    Yes. Send a registration link to anyone. They confirm their phone number and fill the form once, no Eventra account needed.

  • Where is the data stored?

    In a MySQL database on the Eventra server. The Java backend uses JDBC to read and write events, participants, schedules and registrations.

  • Who can use Eventra?

    Colleges, clubs and organizers running workshops, fests, sports meets and conferences.

  • Can developers build with Eventra?

    Yes. The backend exposes events, participants and schedules over a small REST API, so you can connect your own site or app.

This website is the frontend. The backend is a Java application built with event handling, JavaFX and JDBC on a MySQL database. See the backend guide for how it fits together.
